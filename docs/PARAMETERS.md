# 威马桌面 wm24

适配 Android 6.0.1 的轻量车机桌面。首页的数字时间、日期和指针时钟均可点击，进入“详细参数”。支持横屏和竖屏，分类按钮和读数使用大字体。

详情分为常用数据、动力电池、充电状态、行驶与能耗、轮胎状态、电机与制动、门窗与灯光、空调与空气、警告与通信、车辆配置、车辆身份、网络与定位、安卓系统，共 13 类。

已查明的四组原厂 SDK 共 122 个只读方法，展开为 259 个车辆参数项目。常用页优先显示电量、续航、总里程、TRIP A/B、胎压、档位和 READY。其他类别保留全部已查明的读取项目。两项方法的参数含义尚未核实，显示“读取参数待核验”，不会试探未知参数；车型不支持、权限不足、返回无效值均如实显示。列表数量不等于已核实传感器数量，也不代表所有车型均支持这些配置。

复用原厂 Java 服务，另按原生 SDK 读代理逐项核对 85 个原生读取方法。原生服务和 Java AIDL 的查询编号、固定参数、回复格式分别处理，不套用另一套编号，不打包原厂库。参数只在当前详情页可见时每 10 秒更新一次，仅读取选中的分类；切换分类会取消尚未发出的查询，退出后停止刷新。网络定位页通过原厂 TBOX Provider 读取，有定位时可显示位置；内容仅在本地显示。

已核实单位的电量、续航、里程、胎压正常显示；未核实的温度、电压、电流、角度、统计数组等保留原始值并标记待核验。有符号读数保留负数。逐节电芯、完整故障码及原始 CAN 帧没有已查明接口，不提供推算的虚假数据。

新增声明原厂空调和车辆配置读取权限 USE_AIRCONDITION、USE_CARSETUP。它们和现有车辆权限一样属于 signature|privileged；普通安装不一定可用，详情的安卓系统分类显示授权状态。参数页没有车辆写入、故障清除、TRIP 清零和控制按钮。

保留 wm23 的开机主动打开桌面和持久 Home 首选，保留已经确认有效的实体左右切歌。安装独立包 com.wmhome.launcher 可覆盖旧版本并保留配置。学习强国入口分支不能直接覆盖原厂签名与共享 UID 的软件。
